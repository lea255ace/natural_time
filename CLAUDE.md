# Natural Time

Static Next.js site (App Router, `output: 'export'`) that renders a solar clock. Hosted on Neocities.
See `documentation/local-development.md` and `documentation/deployment.md` for setup details.

Planned work and known bugs, in priority order, are in `documentation/roadmap.md`. Check it before starting new
work, and remove an item in the same commit that finishes it.

@AGENTS.md

## Commands

-   Node 24 or later is required (`engines` in `package.json`). Check `node --version` first; older Node
    installs may still be on `PATH`.

-   `npm run dev`, `npm run build` (writes `out/`), `npm run serve`, `npm run lint`, and `npm run check` (lint,
    then build). Run `npm run check` before committing.

-   `npm run deploy` publishes to the live site. Never run it, or rsync to `~/neocities_webdav`, without asking.

-   There are no automated tests. To verify UI changes, drive the page in a browser and interact with it
    (click popovers, submit the config form). Loading a page without errors doesn't prove it hydrated.

## Architecture

-   `app/types/astrolabe.ts` (astronomy) and `app/types/moment.ts` (phase/stage logic) are pure and hold
    the core math. Components only convert their output to rotation angles for layered PNGs.

-   Complications live in `app/components/complications/` and export `Title` and `Display`.

-   Imports are rooted at `app/` via `baseUrl` (for example, `import Clock from 'components/clock'`).

-   `@lea255ace/astro_algo` is a private package on GitHub Packages; installing needs a `read:packages` token.

## Gotchas

-   Static export only: no server actions, route handlers, middleware, or request-time data.

-   MDX remark plugins in `next.config.mjs` must be referenced by name (strings). Turbopack rejects
    function references.

-   React 19 treats invalid nesting as a hydration error. In MDX, indented text inside a JSX block becomes
    a `<p>`, so don't nest it inside `<Text>`.

-   The dev server only allows `localhost` origins by default. `allowedDevOrigins` includes `127.0.0.1`;
    without it the page silently fails to hydrate.

-   Chakra is intentionally on v2 (2.10.x). `@chakra-ui/next-js` only supports v2. A v3 migration is a
    separate, planned effort.

-   ESLint 9 uses the flat config in `eslint.config.mjs`. Ignored files go in its `globalIgnores` list; it doesn't
    read `.gitignore`. `AGENTS.md` is generated by `next dev` and excluded from lint. ESLint 10 is blocked until
    the plugins bundled by `eslint-config-next` accept it as a peer.

-   Neocities rejects rsync's temp-file rename for `index.html`; the deploy script uses `--inplace` for this.

-   There is intentionally no CI. Checks run locally with `npm run check`, and `npm run deploy` lints before it
    builds.

## Conventions

- TypeScript/TSX: 4-space indent, single quotes, semicolons (enforced by ESLint).
- Markdown: lines at most 120 characters (remark-lint).
- Commit messages: one sentence-case summary line ending with a period.
